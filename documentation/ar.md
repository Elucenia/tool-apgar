استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### معدل ضربات القلب

`fc`

- `0` — غير موجود
- `1` — \< ١٠٠ ضربة/دقيقة
- `2` — ≥ ١٠٠ ضربة/دقيقة

### الجهد التنفسي

`resp`

- `0` — غير موجود
- `1` — بطيء وغير منتظم
- `2` — جيّد، بكاء قوي

### توتر العضلات

`tonus`

- `0` — رخو
- `1` — بعض الثني
- `2` — حركات نشطة

### الاستجابة الانعكاسية

`reflexo`

- `0` — دون استجابة
- `1` — تكشير
- `2` — بكاء أو سعال أو عطاس

### اللون

`cor`

- `0` — زرقة أو شحوب
- `1` — جسم وردي وأطراف مزرقة
- `2` — ورديّ بالكامل

## إصدار الطريقة

أبغار 1953: 5 علامات 0–2؛ متابعة AAP/ACOG 2015 عند 1/5 min وتكرار إذا \<7

## المعادلة الموثقة

خمس علامات، كل منها 0 إلى 2: النبض وجهد التنفس والتوتر العضلي والاستجابة المنعكسية واللون. المجموع 0 إلى 10 عند الدقيقة 1 و5؛ إذا كانت عند 5 دقائق \<7 فكرّر كل 5 حتى 20 دقيقة.

## الحدود والفئة السكانية

يسجل أبغار حالة المولود الجديد واستجابته للإنعاش؛ ولا يحدد الخطوات الأولية للإنعاش، ولا يشخّص الاختناق، ولا يتنبأ وحده بوفاة الفرد أو بمآله العصبي. لا يعادل التقييم الممنوح أثناء الإنعاش التقييم أثناء التنفس التلقائي. قد تؤثر الولادة المبكرة وأدوية الأم والتفاوت في الفحص في النتيجة.

## إعادة إجراء الاختبارات التقنية

شغّل node test.cjs في المجلد الجذري لهذا المستودع لتكرار الحالات الاصطناعية المسجلة. تُحفظ المدخلات والنتائج المتوقعة وحدود التفاوت الأصلية. لا تُعدّ الاختبارات التقنية تحققًا سريريًا.

```sh
node test.cjs
```
